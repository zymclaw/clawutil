1. 背景：从手动同步到Agent驱动

一直以来，百度网盘在命令行生态里几乎是"隐形"的。想在终端里上传文件？要么用第三方工具（BaiduPCS-Go），要么老老实实打开客户端拖文件。

我的日常工作流是这样的：下载播客音频 → 转MP3 → 复制到百度云盘同步空间 → 等同步。中间还踩过一个坑——文件名里有 | 字符，百度网盘同步直接报错，文件名静默失败。于是我在 podcast-downloader 里加了一层文件名清洗，用 - 替换特殊字符。

这种"被动同步"模式有两个问题：

  • 延迟：文件复制到同步空间后，要等客户端同步完成，几十MB的文件不是秒传的
  • 不可控：同步失败了你不知道，特殊字符导致的问题排查了半天

直到最近发现百度网盘官方出了一个 AI Agent Skill——bdpan-storage，才真正实现了"主动上传"。

2. bdpan-storage 是什么

为 Agent 构建可交付的数字记忆——百度网盘官方Skill，让 AI Agent 拥有上传、下载、分享、备份记忆等完整云端能力。

bdpan-storage 是百度网盘官方团队开发的 AI Agent Skill，适配 Claude Code、OpenClaw、Cursor、Gemini CLI 等主流 Agent 平台。它包含两部分：

  • bdpan CLI：Go 语言编写的命令行工具，提供上传、下载、搜索、分享等完整网盘操作
  • Skill 定义：SKILL.md + 参考文档 + 管理脚本，定义了 Agent 如何安全地使用 CLI

GitHub 仓库：github.com/baidu-netdisk/bdpan-storage

安装一条命令：

npx skills add https://github.com/baidu-netdisk/bdpan-storage/skills --skill baidu-drive

3. 功能全景

⬆️ 上传

单文件/文件夹上传，支持递归和进度显示。远端路径自动创建目录。

⬇️ 下载

直接下载或通过分享链接下载。大文件自动后台下载+进度轮询。

🔗 分享

生成分享链接（1天/7天/30天/永久），自动返回提取码。

🔄 转存

将分享链接内容转存到自己网盘，不下载到本地。

🔍 搜索

按关键词/类型搜索，支持视频/音频/图片/文档等分类过滤。

📁 文件管理

移动、复制、重命名、创建文件夹，完整的文件管理能力。

🧠 记忆备份

自动备份 Agent 的 Workspace 文件（AGENTS.md、MEMORY.md 等）到网盘，支持恢复。

📊 JSON 输出

所有命令支持 --json 标志，便于脚本解析和自动化。

完整命令列表

命令功能示例
bdpan upload上传文件/文件夹bdpan upload ./file.pdf docs/file.pdf
bdpan download下载文件/文件夹bdpan download docs/file.pdf ./file.pdf
bdpan ls查看文件列表bdpan ls podcast/ --desc
bdpan share创建分享链接bdpan share file.pdf --period 7
bdpan transfer转存分享链接bdpan transfer "https://..." -p abcd
bdpan search搜索文件bdpan search 报告 --category 4
bdpan mv移动文件bdpan mv file.pdf backup/
bdpan cp复制文件bdpan cp file.pdf archive/
bdpan rename重命名bdpan rename old.pdf new.pdf
bdpan mkdir创建文件夹bdpan mkdir projects/2026
bdpan whoami查看登录状态bdpan whoami

4. 安全设计：大厂的谨慎

这是我觉得最值得说的一点。作为一个第三方 CLI 工具，bdpan 的安全设计比很多同类工具都严格：

安全特性说明
作用域隔离所有操作限制在 /apps/bdpan/ 目录，无法访问用户其他文件
无删除命令不提供 rm 命令，从根本上防止误删
OAuth 2.0授权码模式认证，不存储用户密码
Token 保护配置文件含 Token，Agent 禁止读取或输出其内容
安全传码授权码通过 stdin 传递，不暴露在进程列表中
SHA256 校验安装和更新的二进制文件强制完整性校验
更新需确认禁止自动或静默更新，必须用户明确指令并确认
修改前确认移动、重命名、覆盖等操作执行前必须用户确认
💡 亮点：作用域隔离 + 无删除命令，这两条设计非常聪明。Agent 能做的事被限制在安全范围内，即使 AI "抽风"也不会影响你网盘里的其他文件。

当然，这也意味着一个限制——你不能用它管理网盘根目录的文件，只能操作 /apps/bdpan/ 下的内容。对于大多数场景够用了。

5. 安装与配置

一键安装 Skill

npx skills add https://github.com/baidu-netdisk/bdpan-storage/skills --skill baidu-drive

安装完成后，首次使用会自动引导 CLI 安装和登录授权。

手动安装 CLI（如果自动安装失败）

# macOS ARM64
bash ~/.openclaw/workspace/skills/baidu-drive/scripts/install.sh

# 登录
bash ~/.openclaw/workspace/skills/baidu-drive/scripts/login.sh

登录流程

支持三种登录方式：

  • OAuth 授权码：打开浏览器，复制授权码粘贴
  • 设备码登录：扫码授权，无需手动复制（推荐）
  • 二维码登录：百度APP扫码
# 设备码登录（推荐）
bdpan login --device-code --accept-disclaimer

# 查看登录状态
bdpan whoami
⚠️ 注意：Token 有效期约 30 天，过期后需要重新登录。Agent 会自动检测并引导你重新授权。

6. 实战：播客下载+网盘上传一条龙

我之前写过一个 podcast-downloader Skill，用于从小宇宙下载播客。现在集成 bdpan 后，整个流程变成了一条龙：

一条命令搞定

UPLOAD_TO_BDPAN=true ./download.sh "https://www.xiaoyuzhoufm.com/episode/xxx"

执行流程

  1. 从小宇宙抓取播客信息（标题、音频URL、Show Notes）
  2. 下载 m4a 音频文件
  3. ffmpeg 转换为 MP3（兼容骨传导耳机离线播放）
  4. 保存 Show Notes 为 Markdown
  5. 自动上传 MP3 + Markdown 到百度网盘 /apps/bdpan/podcast/

💡 文件名清洗：小宇宙播客标题经常包含 |、： 等特殊字符，百度网盘会报错。脚本自动用 - 替换，确保上传成功。

7. 可以做得更好的地方

用了一天，整体体验不错，但有几个地方我觉得可以改进：

① 上传缺少覆盖策略

现状：上传同名文件会报错 errno=-7，没有 skip/overwrite/rsync 策略。
建议：参考 BaiduPCS-Go 的 --policy skip|overwrite|rsync 参数，让用户选择冲突处理方式。
Workaround：上传前先 bdpan ls --json 检查远端是否已存在。

② 作用域限制过死

现状：只能操作 /apps/bdpan/ 目录，无法访问用户其他网盘文件。
建议：增加一个 --scope extended 参数，允许用户授权访问更多目录。
影响：如果你想把文件上传到网盘根目录的某个现有文件夹，做不到。

③ 缺少批量操作

现状：每次只能上传一个文件/文件夹，没有 glob 模式支持。
建议：支持 bdpan upload ./podcasts/*.mp3 podcast/ 这样的批量上传。
Workaround：用 shell 循环实现，但效率低且没有并发。

④ 没有增量同步

现状：没有 sync 命令，无法实现本地目录与网盘的增量同步。
建议：增加 bdpan sync ./local-dir/ remote-dir/，只上传新增/修改的文件。
场景：Obsidian Vault 同步、定期备份等。

⑤ 进度显示不够精确

现状：大文件上传时没有进度百分比，只有"正在上传..."。
建议：参考 curl --progress-bar 的实现，显示上传速度、已传大小、预计剩余时间。

⑥ Windows 原生不支持

现状：只支持 macOS、Linux、Windows WSL，不支持 Windows 原生。
影响：大部分中国用户用 Windows，这个限制比较遗憾。

8. 总结

bdpan-storage 是百度网盘在 AI Agent 生态里的一次重要布局。虽然还是公测阶段，但核心功能已经可用，安全设计也比很多第三方工具严格。

适合谁用

  • ✅ 用 OpenClaw/Claude Code 等 Agent 的开发者
  • ✅ 需要自动化文件管理的命令行用户
  • ✅ 想给 Agent 添加云端存储能力的团队

不适合谁

  • ❌ 需要管理网盘根目录文件的用户（作用域限制）
  • ❌ 需要删除功能的场景（无 rm 命令）
  • ❌ Windows 原生用户（需 WSL）

一句话评价

大厂出品，安全第一，功能够用，还有进步空间。比起"百度网盘出了个 CLI 工具"，更值得关注的是"百度在认真对待 AI Agent 生态"这件事本身。
