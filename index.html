ClawHub 与 VirusTotal 达成战略合作
为 AI 技能市场树立安全新标杆

OpenClaw 引入全球领先威胁情报平台，为所有技能提供自动化安全扫描与 AI 代码分析

2026年2月22日 安全公告 OpenClaw 团队

我们很高兴地宣布，OpenClaw 已与 VirusTotal（谷歌旗下全球领先的威胁情报平台）达成战略合作伙伴关系。即日起，所有提交至 ClawHub 的技能都将接受 VirusTotal 的自动化安全扫描，包括其最新的 Code Insight AI 分析能力。

为什么这对 AI 代理生态至关重要

传统安全模型围绕"锁定"设备建立，但 AI 代理代表根本性的范式转变。与传统软件不同，AI 代理理解自然语言并自主决策，模糊了用户意图与机器执行的边界。一个设计不当的 AI 代理可能成为安全漏洞，而设计得当则能彻底改变个人计算体验。

"

随着 OpenClaw 生态的发展，攻击面也在扩大。我们已经看到恶意行为者试图利用 AI 代理平台的案例。我们不会等到问题恶化才采取行动。

七层安全防护机制

1

确定性打包

技能文件统一打包为 ZIP，包含 _meta.json 发布者信息

2

哈希值计算

计算 SHA-256 哈希值，创建唯一数字指纹

3

VirusTotal 查询

自动查询数据库，如有 Code Insight 结果立即返回

4

上传与分析

通过 VirusTotal v3 API 上传进行全新扫描

5

Code Insight AI 分析

Gemini 驱动，从安全角度分析代码实际行为

6

自动审批与拦截

良性自动通过，可疑标记警告，恶意立即阻断

7

每日重新扫描

检测先前安全技能是否被篡改或更新后变为恶意

重要说明：这不是万能药

VirusTotal 扫描无法捕获所有威胁。通过自然语言指示代理执行恶意操作的技能不会触发病毒特征码。安全是纵深防御，这只是第一层防护。

提供的实际保护

  • ✓ 已知恶意软件检测 — 木马、窃取器、后门、恶意载荷
  • ✓ 行为分析 — Code Insight 识别新型威胁中的可疑模式
  • ✓ 供应链可见性 — 捕获受损依赖项和嵌入式可执行文件
  • ✓ 安全意图信号 — 表明我们对安全的投入，这只是众多防护层的第一步
