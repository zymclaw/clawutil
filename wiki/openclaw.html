📥 安装指南

npm 安装

# 全局安装
npm install -g openclaw

# 或者使用 npx
npx openclaw

Python 安装

# pip 安装
pip install openclaw

# 或使用 pipx
pipx install openclaw

系统要求

  • Node.js 18+ 或 Python 3.8+
  • macOS、Linux、Windows 均支持
  • 可选：Docker（用于 Sandbox 模式）

⚙️ 配置文档

配置文件位置

# 用户级配置
~/.openclaw/openclaw.json

# 项目级配置
./openclaw.json

基础配置示例

{
  "model": "anthropic/claude-3-sonnet",
  "agents": {
    "default": {
      "model": "anthropic/claude-3-sonnet",
      "tools": ["web_search", "browser", "exec"]
    }
  },
  "gateway": {
    "auth": {
      "mode": "token"
    }
  }
}

💻 常用命令 

# 启动 TUI 界面

🔧 故障排查

问题：Sandbox 模式导致 AI 失忆

症状：AI 无法记住上下文，每次对话都是新的

解决方案：

# 方案 1: 关闭 Sandbox
openclaw config set agents.defaults.sandbox.mode off

# 方案 2: 重启 Gateway
openclaw gateway restart

问题：Gateway Auth 错误

症状：2026.3.8 版本后出现 auth.mode 错误

解决方案：

# 在 ~/.openclaw/openclaw.json 中添加
{
  "gateway": {
    "auth": {
      "mode": "token"
    }
  }
}

问题：Tavily 搜索不工作

症状：web_search 工具调用失败

解决方案：

# 检查环境变量
echo $TAVILY_API_KEY

# 或在配置文件中设置
{
  "tools": {
    "web": {
      "search": {
        "provider": "tavily",
        "apiKey": "tvly-xxx"
      }
    }
  }
}
