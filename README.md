
## Skills

### podcast-downloader 🎙️

从小宇宙下载播客音频，自动转换为 MP3 格式，支持骨传导耳机离线播放。

**安装**：
```bash
cp -r skills/podcast-downloader ~/.openclaw/workspace/skills/
```

**使用**：
```bash
./skills/podcast-downloader/scripts/download.sh "https://www.xiaoyuzhoufm.com/episode/xxx"
```
